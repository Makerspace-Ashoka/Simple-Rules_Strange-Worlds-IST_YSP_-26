# Challenge 07: Programming Life

**Difficulty: Expert**

**Objective:** Create a programmable Game of Life where users can define conditional behaviours for cells.

**Instructions:**
1. Create a simple programming language or rule system for cells:
   - Conditions based on neighbouring states
   - Actions to take (change state, emit signals, etc.)
   - Variables to store information
2. Design a UI for programming cell behaviours
3. Implement an interpreter for your cell programming language
4. Create visualisations for program execution

**Hints:**
- Start with a simple if-then syntax for cell behaviour
- Use a block-based programming interface (like Scratch) for easier use
- Allow different regions to have different programs
- Create predefined programs for common behaviours

**Extension:** Implement cell "species" that have different programmed behaviours and can evolve over time.
