# Challenge 05: Statistical Analysis

**Difficulty: Intermediate-Advanced**

**Objective:** Add tools to analyze the behavior of the Game of Life over time.

**Instructions:**
1. Create a population graph that shows changes over time
2. Track and display statistics like:
   - Population (live cells)
   - Births and deaths per generation
   - Growth rate (percentage change)
3. Detect and display pattern classifications:
   - Stable (population doesn't change)
   - Oscillating (population cycles)
   - Growing or shrinking trends

**Hints:**
- Use arrays to store historical data for graphing
- Display the graph in a separate panel or overlay
- Use basic statistics to detect patterns in population changes

**Extension:** Implement pattern detection for common structures like still lifes, oscillators, and gliders.
