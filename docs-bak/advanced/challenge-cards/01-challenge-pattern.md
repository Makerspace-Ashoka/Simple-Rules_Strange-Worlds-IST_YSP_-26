# Challenge 01: Pattern Explorer

**Difficulty: Beginner-Intermediate**

**Objective:** Enhance the Game of Life with additional patterns and pattern manipulation.

**Instructions:**
1. In the `patterns.js` file, add at least two new patterns of your own design
2. Implement a function to rotate patterns (90, 180, or 270 degrees)
3. Add buttons to the UI for rotating patterns before placement
4. Test your patterns to see how they evolve over time

**Hints:**
- Start with simple patterns and observe their behavior
- For rotation, create a function that takes a pattern array and returns a new rotated array
- Test your rotation function separately before integrating it

**Extension:** Create a "random small pattern" function that generates patterns of size 4x4 with random cells.
