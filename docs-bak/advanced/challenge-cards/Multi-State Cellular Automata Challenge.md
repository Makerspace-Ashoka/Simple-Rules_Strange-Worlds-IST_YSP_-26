# Challenge 06: Multi-State Cellular Automata

**Difficulty: Advanced**

**Objective:** Extend Conway's Game of Life to support multiple cell states.

**Instructions:**
1. Modify the grid to store values beyond 0 and 1 (e.g., 0=dead, 1=young, 2=mature, 3=dying)
2. Create transition rules between these states
3. Implement different colours for each state
4. Add UI controls to adjust transition rules

**Hints:**
- Start with a simple life cycle: birth → mature → dying → dead
- Use a colour gradient to visualize the different states
- Design rules that create interesting patterns with multiple states

**Extension:** Create a competitive version where two or more "species" (different states) compete for territory on the Life of grid.
