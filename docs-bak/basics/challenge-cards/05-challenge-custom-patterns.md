# Challenge 05: Custom Patterns

**Difficulty: Intermediate**

**Objective:** Create a system for saving and placing custom patterns.

**Instructions:**
1. Create a new function `saveCurrentPattern()` that stores the current grid state (or a portion of it)
2. Add a "Save Pattern" button to the UI that lets users save the current pattern
3. Think how a user can name patterns?
4. Create a button to place the saved pattern on the grid. Use the name your user gave.

**Hints:**
- Store patterns as 2D arrays similar to the predefined patterns
- You might need to decide on a fixed size for custom patterns (e.g., 10x10)
- Allow users to name their patterns

**Advanced Extension:** Save patterns to `localStorage` so they persist between sessions.
