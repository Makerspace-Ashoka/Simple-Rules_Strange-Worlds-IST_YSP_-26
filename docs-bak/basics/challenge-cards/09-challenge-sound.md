# Challenge 09: Sound Effects

**Difficulty: Advanced**

**Objective:** Add sound effects that respond to simulation events.

**Instructions:**
1. Use the p5.sound library to create sound effects
2. Add sounds that trigger based on events like:
   - Births and deaths
   - Population reaching certain thresholds
   - Interesting patterns forming (like oscillators)
3. Create a function that generates musical notes based on grid activity

**Hints:**
- Start with simple sounds for basic events
- Use the population count to control pitch or volume
- Consider using oscillators or synthesisers for more complex sounds

**Extension:** Create a "music mode" that turns the Game of Life into a generative music tool, where different regions of the grid control different instruments or sounds.
