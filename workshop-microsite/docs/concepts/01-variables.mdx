# Variables

A **variable** is a named place where a program stores information.

Think of a variable like a **labeled box**.

The label tells us what the box is for, and the value inside the box is the information being stored.

```js
let score = 0;
```

In this example:

- `score` is the variable name
- `0` is the value stored inside it

---

## Why Do We Need Variables?

Programs often need to remember things.

For example:

```js
let score = 0;
let lives = 3;
let playerName = "Ada";
let isAlive = true;
```

These variables help the program remember:

- the player's score
- how many lives are left
- the player's name
- whether the player is still active

Without variables, a program would have no easy way to keep track of changing information.

---

## Variables Can Change

The value inside a variable can change while the program runs.

```js
let score = 0;

score = 10;
score = 25;
```

The name `score` stays the same, but the value changes.

This is useful because many things in a program change over time.

Examples:

- a score increases
- energy goes down
- temperature changes
- a cell changes state
- an object moves position

## Variables in Simulations

Simulations need variables because simulations are full of changing information.

A simulation might store:

```js
let temperature = 25;
let population = 100;
let speed = 2;
let cellState = "active";
let isBurning = false;
```

These variables describe what is happening **right now**.

As the simulation runs, the values can update.

For example:

```js
temperature = temperature + 1;
population = population - 5;
isBurning = true;
```

Variables help the program remember the current state of the simulation.

---

## Good Variable Names

Variable names should be clear.

Bad:

```js
let x = 3;
```

Better:

```js
let lives = 3;
```

The second version is easier to understand because the name tells us what the value means.

Use names that describe the information being stored.

Examples:

```js
let playerScore = 0;
let rabbitEnergy = 100;
let windSpeed = 5;
let cellState = "empty";
let isInfected = false;
```

---

## Key Idea

A variable has two main parts:

```js
let score = 10;
```

| Part | Meaning |
| --- | --- |
| `score` | the name |
| `10` | the value |

A variable lets the program store a value, use it later, and change it when needed.
