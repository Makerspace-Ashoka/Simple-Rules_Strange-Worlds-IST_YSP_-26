# Conditionals

A **conditional** lets a program make a decision.

It checks whether something is true or false, then chooses what to do next.

```js
if (isRaining) {
  takeUmbrella();
} else {
  wearSunglasses();
}
```

This means:

> If it is raining, take an umbrella.  
> Otherwise, wear sunglasses.

---

## Why Do We Need Conditionals?

Programs often need to choose between different actions.

Examples:

- if the player has no lives left, end the game
- if a cell is active, update it
- if the temperature is high, spread fire
- if the simulation is running, keep updating
- if the rabbit is hungry, make it search for food

Conditionals let code respond to what is happening.

---

## If Statements

An `if` statement runs code only when a condition is true.

```js
let score = 80;

if (score > 50) {
  console.log("You passed!");
}
```

Here, the condition is:

```js
score > 50
```

Since `80 > 50` is true, the message will run.

---

## Else Statements

An `else` statement runs when the condition is false.

```js
let score = 30;

if (score > 50) {
  console.log("You passed!");
} else {
  console.log("Try again.");
}
```

Since `30 > 50` is false, the program runs the `else` block.

---

## Else If Statements

Sometimes there are more than two possible paths.

```js
let score = 72;

if (score >= 80) {
  console.log("Gold badge");
} else if (score >= 50) {
  console.log("Silver badge");
} else {
  console.log("Try again");
}
```

This lets the program check several conditions in order.

## Comparison Operators

Conditionals often use comparison operators.

| Operator | Meaning | Example |
| --- | --- | --- |
| `>` | greater than | `score > 50` |
| `<` | less than | `temperature < 20` |
| `>=` | greater than or equal to | `score >= 80` |
| `<=` | less than or equal to | `energy <= 0` |
| `===` | equal to | `cellState === "alive"` |
| `!==` | not equal to | `cellState !== "empty"` |

Each comparison gives a boolean result:

```js
true
```

or

```js
false
```

## Booleans and Conditionals

A condition usually asks a true-or-false question.

```js
let isAlive = true;

if (isAlive) {
  console.log("The cell is alive.");
}
```

The variable `isAlive` already stores a boolean value, so it can be used directly inside the condition.

---

## Conditionals in Simulations

Simulations use conditionals to apply rules.

Example:

```js
if (temperature > 30) {
  fireSpreads = true;
} else {
  fireSpreads = false;
}
```

Another example:

```js
if (cellState === "active") {
  updateCell();
}
```

Conditionals help the simulation decide what happens next.

They are useful for rules like:

- if a cell is alive, check whether it survives
- if a tree is burning, turn it into ash
- if an animal has low energy, make it search for food
- if a raindrop reaches the ground, stop falling
- if the simulation is paused, stop updating

---

## Key Idea

A conditional lets the program choose between actions.

```js
if (condition) {
  // do this when true
} else {
  // do this when false
}
```

The program checks the condition first.

Then it follows the correct path.
