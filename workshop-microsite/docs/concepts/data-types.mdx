# Data Types

A **data type** tells the computer what kind of value it is working with.

Different values behave differently.

For example:

```js
let score = 10;
let name = "Ada";
let isAlive = true;
```

These values are not the same kind of information.

- `10` is a number
- `"Ada"` is text
- `true` is a true-or-false value

Data types help the computer know what it can do with each value.

---

## Three Common Data Types

### 1. Numbers

Numbers are used for counting, measuring, and calculations.

```js
let score = 100;
let speed = 5;
let temperature = 28;
```

Numbers can be added, subtracted, multiplied, divided, and compared.

```js
score = score + 10;
temperature = temperature - 2;
```

---

### 2. Text / Strings

Text values are called **strings**.

Strings are used for words, names, labels, and messages.

```js
let playerName = "Ada";
let cellType = "tree";
let message = "Simulation started";
```

Strings usually go inside quotation marks.

```js
"hello"
"fire"
"rabbit"
```

---

### 3. Booleans

A **boolean** stores only one of two values:

```js
true
false
```

Booleans are useful for yes-or-no information.

```js
let isAlive = true;
let isBurning = false;
let simulationRunning = true;
```

A boolean can answer questions like:

- Is the cell active?
- Is the object moving?
- Is the simulation still running?
- Is the condition true?

## Why Data Types Matter

The computer treats different data types differently.

For example:

```js
10 + 5
```

gives:

```js
15
```

But:

```js
"10" + "5"
```

gives:

```js
"105"
```

The first example uses numbers.

The second example uses strings.

Same symbol, different data type, different result.

---

## Data Types in Simulations

Simulations use many data types at the same time.

For example:

```js
let cellAge = 3;
let cellType = "tree";
let isBurning = false;
```

Here:

| Variable | Value | Data Type |
| --- | --- | --- |
| `cellAge` | `3` | number |
| `cellType` | `"tree"` | string |
| `isBurning` | `false` | boolean |

This lets the simulation store different kinds of information about the same cell or object.

---

## Key Idea

A data type tells the computer what kind of value it is using.

| Data Type | Example | Used For |
| --- | --- | --- |
| Number | `42` | counting and calculations |
| String | `"rabbit"` | words and labels |
| Boolean | `true` | yes-or-no states |
