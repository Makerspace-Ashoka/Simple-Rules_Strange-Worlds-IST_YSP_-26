# What is Programming?

Programming means giving a computer clear, step-by-step instructions that it can follow.

A computer does not guess what you mean. It follows the instructions exactly as they are written.

Think of a computer like a very powerful robot helper:

- it can repeat tasks quickly
- it can store information
- it can follow rules
- it can update a simulation many times

But it needs instructions that are precise.

## A Simple Example

Imagine you tell a robot:

> Draw a house.

That sounds clear to a human, but it is too vague for a computer.

The robot needs smaller steps:

1. Draw a square.
2. Add a triangle roof.
3. Add a door.
4. Add two windows.

Now the instruction is easier to follow.

That is the heart of programming: breaking a big idea into clear steps.

## Programming and Simulations

In this workshop, we will use programming to build simulations.

A simulation is a program that models how something changes over time.

Examples of things we can simulate:

- cells changing on a grid
- fire spreading through a forest
- animals moving through an environment
- disease spreading through a population
- traffic moving through a city

A simulation usually needs:

- **state**: what is happening right now
- **rules**: how things change
- **time steps**: repeated updates
- **display**: a way to see what is happening

Programming gives us a way to describe all of this clearly.

## Programming Is Not Just Code

Coding is writing instructions in a programming language.

Programming is bigger than that.

Programming includes:

- understanding the problem
- breaking it into steps
- writing instructions
- testing if they work
- fixing mistakes
- improving the result

So when we program, we are not just typing code.

We are learning how to think clearly.

## Key Idea

A program is a set of instructions.

A good program is:

- clear
- specific
- ordered
- testable

If the computer cannot follow the instructions without guessing, the instructions need to be improved.

## Challenge Cards

### Challenge Card 1: Robot Instructions

Choose one everyday task:

- brushing your teeth
- making noodles
- tying your shoes
- packing your bag
- watering a plant

Write the task as 5 exact steps.

Then ask:
Could a robot follow these steps without guessing?

### Challenge Card 2: Fix the Vague Command

This command is too vague:

```javascript
makeFood();
```

Rewrite it as smaller steps.

### Challenge Card 3: Simulation Thinking

Pick one system you could simulate.

Examples:

- rain falling
- fire spreading
- rabbits moving
- traffic lights changing
- cells turning on and off

Answer:

- What things exist in the simulation?
- What rules do they follow?
- What changes over time?
- What should the viewer see?
