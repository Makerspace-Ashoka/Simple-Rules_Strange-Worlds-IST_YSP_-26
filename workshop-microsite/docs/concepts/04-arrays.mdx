# Arrays and 2D Arrays

An **array** stores many values under one name.

Instead of creating many separate variables:

```js
let score1 = 8;
let score2 = 12;
let score3 = 15;
let score4 = 10;
```

we can store the values together:

```js
let scores = [8, 12, 15, 10];
```

This is an array.

---

## Why Do We Need Arrays?

Programs often need to work with many related values.

Examples:

- many scores
- many names
- many cells
- many particles
- many animals
- many positions in a simulation

Arrays help us keep related values organized.

```js
let animals = ["rabbit", "fox", "bird"];
let temperatures = [25, 27, 30, 28];
let cellStates = [0, 1, 0, 1];
```

---

## Indexes

Each value in an array has a position called an **index**.

In JavaScript, indexes start at `0`.

```js
let scores = [8, 12, 15, 10];
```

| Index | Value |
| --- | --- |
| `0` | `8` |
| `1` | `12` |
| `2` | `15` |
| `3` | `10` |

To access a value, use its index:

```js
console.log(scores[0]); // 8
console.log(scores[2]); // 15
```

---

## Updating an Array

Values inside an array can change.

```js
let scores = [8, 12, 15, 10];

scores[1] = 20;
```

Now the array becomes:

```js
[8, 20, 15, 10]
```

The array name stays the same, but one value inside it changes.

---

## Loops and Arrays

Loops work well with arrays because a loop can visit each value one by one.

```js
let scores = [8, 20, 15, 10];

for (let i = 0; i < scores.length; i++) {
  console.log(scores[i]);
}
```

This means:

> Start at the first value, then visit each value until the array ends.

This is useful when we want to update many things in a program or simulation.

# 2D Arrays

A **2D array** stores values in rows and columns.

It is like a grid.

```js
let grid = [
  [1, 0, 1],
  [0, 1, 0],
  [1, 1, 0]
];
```

This grid has:

- 3 rows
- 3 columns
- 9 total values

---

## Rows and Columns

To access a value in a 2D array, we use two indexes:

```js
grid[row][column]
```

Example:

```js
let grid = [
  [1, 0, 1],
  [0, 1, 0],
  [1, 1, 0]
];

console.log(grid[0][0]); // 1
console.log(grid[1][2]); // 0
console.log(grid[2][1]); // 1
```

The first index chooses the row.

The second index chooses the column.

---

## 2D Arrays in Simulations

2D arrays are useful for simulations because many simulations happen on grids.

Examples:

- cells changing state
- fire spreading
- rain falling
- animals moving
- particles flowing
- terrain changing

A grid can store the current state of the simulation.

```js
let grid = [
  [0, 0, 0],
  [0, 1, 0],
  [0, 0, 0]
];
```

Here, we could say:

```js
0 = empty
1 = active
```

The program can then update the grid over time.

---

## Updating Every Cell in a Grid

To update a 2D array, we often use one loop inside another loop.

```js
for (let row = 0; row < grid.length; row++) {
  for (let col = 0; col < grid[row].length; col++) {
    updateCell(row, col);
  }
}
```

The first loop visits each row.

The second loop visits each cell in that row.

This lets the program check and update every position in the grid.

---

## Key Idea

An array stores many values in a row.

```js
let scores = [8, 12, 15, 10];
```

A 2D array stores values in rows and columns.

```js
let grid = [
  [0, 1, 0],
  [1, 1, 0],
  [0, 0, 1]
];
```

Arrays help us store many related values.

2D arrays help us store grid-based worlds.
