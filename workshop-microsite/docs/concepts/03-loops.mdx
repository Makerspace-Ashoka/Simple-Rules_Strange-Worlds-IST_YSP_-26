# Loops

A **loop** lets a program repeat instructions.

Instead of writing the same instruction again and again, we can tell the computer:

> Repeat this action.

Example:

```js
for (let i = 0; i < 5; i++) {
  console.log("Hello");
}
```

This prints `"Hello"` five times.

---

## Why Do We Need Loops?

Programs often need to repeat actions.

Examples:

- count from 1 to 10
- move a character step by step
- check every item in a list
- update every cell in a grid
- keep a simulation running over time

Without loops, repeated code becomes messy.

Bad:

```js
console.log("Hello");
console.log("Hello");
console.log("Hello");
console.log("Hello");
console.log("Hello");
```

Better:

```js
for (let i = 0; i < 5; i++) {
  console.log("Hello");
}
```

A loop keeps the code shorter and easier to change.

---

## For Loops

A **for loop** is useful when we know how many times something should repeat.

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

This gives:

```js
0
1
2
3
4
```

The variable `i` is the counter.

It starts at `0`, increases each time, and stops when the condition is no longer true.

---

## Understanding the Parts

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

| Part | Meaning |
| --- | --- |
| `let i = 0` | start counting from 0 |
| `i < 5` | keep going while this is true |
| `i++` | increase `i` by 1 each time |
| `console.log(i)` | repeat this instruction |

---

## While Loops

A **while loop** repeats while a condition is true.

```js
let energy = 100;

while (energy > 0) {
  console.log("Keep running");
  energy = energy - 25;
}
```

This means:

> While energy is greater than 0, keep running.

When `energy` becomes `0`, the loop stops.

---

## For Loop vs While Loop

| Loop Type | Best Used When |
| --- | --- |
| `for` loop | you know how many times to repeat |
| `while` loop | you repeat until a condition changes |

Example:

```js
for (let i = 0; i < 10; i++) {
  jump();
}
```

Use this when you know the action should happen 10 times.

```js
while (simulationRunning) {
  updateSimulation();
}
```

Use this when the action should continue until something changes.

## Loops in Simulations

Simulations need loops because they change over time.

A simulation usually does not update only once.

It updates again and again.

```js
while (simulationRunning) {
  updateWorld();
  drawWorld();
}
```

This lets the simulation keep moving.

Loops can also update many objects:

```js
for (let i = 0; i < cells.length; i++) {
  updateCell(cells[i]);
}
```

This means:

> Visit each cell and update it.

Loops are important because simulations often contain many things changing at once.

---

## Loops and Time Steps

A simulation often moves in **time steps**.

At each time step:

1. check the current state
2. apply the rules
3. update the system
4. display the result

Example:

```js
while (simulationRunning) {
  applyRules();
  updateState();
  drawSimulation();
}
```

Each repeat of the loop is one step forward in time.

---

## Key Idea

A loop repeats instructions.

```js
for (let i = 0; i < 5; i++) {
  doSomething();
}
```

This means:

> Do something five times.

Loops help us avoid repeated code and make simulations run over time.
