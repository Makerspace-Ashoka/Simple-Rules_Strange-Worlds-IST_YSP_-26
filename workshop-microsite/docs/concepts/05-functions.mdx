# Functions

A **function** is a named block of reusable instructions.

Instead of writing the same steps again and again, we can give the steps a name and use them whenever we need them.

```js
function greetPlayer() {
  console.log("Welcome to the simulation!");
}
```

To use the function, we **call** it:

```js
greetPlayer();
```

---

## Why Do We Need Functions?

Programs can become messy when the same instructions are repeated many times.

Without a function:

```js
console.log("Draw cell");
console.log("Check state");
console.log("Update cell");

console.log("Draw cell");
console.log("Check state");
console.log("Update cell");
```

With a function:

```js
function updateCell() {
  console.log("Draw cell");
  console.log("Check state");
  console.log("Update cell");
}

updateCell();
updateCell();
```

Functions make code:

- easier to read
- easier to reuse
- easier to test
- easier to debug
- easier to improve

---

## A Function Is Like a Recipe

Think of a function like a recipe card.

A recipe has:

1. a name
2. ingredients
3. steps
4. a result

A function works in a similar way.

It can have:

1. a name
2. inputs
3. instructions
4. an output

Example:

```js
function makeJuice(fruit) {
  return fruit + " juice";
}
```

Calling the function:

```js
makeJuice("orange");
```

Output:

```js
"orange juice"
```

---

## Function Names

A function name should describe what the function does.

Good function names:

```js
drawCell();
updateGrid();
countNeighbors();
moveRabbit();
spreadFire();
```

Bad function names:

```js
doThing();
x();
stuff();
```

Clear names make code easier to understand.

---

## Inputs / Parameters

Some functions need information before they can work.

That information is called an **input** or **parameter**.

```js
function double(number) {
  return number * 2;
}
```

Here, `number` is the input.

Calling the function:

```js
double(5);
```

Output:

```js
10
```

---

## Return Values

A function can give back a result using `return`.

```js
function add(a, b) {
  return a + b;
}
```

Calling the function:

```js
let answer = add(3, 4);
```

Now:

```js
answer = 7;
```

The function calculates a value and gives it back.

## Functions in Simulations

Functions are very useful in simulations because simulations often repeat the same actions.

For example, a simulation might need functions like:

```js
function updateCell() {
  // update one cell
}

function drawGrid() {
  // display the grid
}

function countNeighbors() {
  // count nearby cells
}
```

Instead of writing all the code in one large block, we can organize the simulation into smaller functions.

---

## Example: Updating a Cell

A simulation might have a function that updates one cell.

```js
function updateCell(cellState, neighborCount) {
  if (neighborCount > 2) {
    return "active";
  } else {
    return cellState;
  }
}
```

This function takes:

- the current cell state
- the number of nearby active cells

Then it returns the next state.

This makes the simulation easier to understand and easier to debug.

---

## Example: Drawing a Grid

A function can also handle drawing.

```js
function drawGrid(grid) {
  for (let row = 0; row < grid.length; row++) {
    for (let col = 0; col < grid[row].length; col++) {
      drawCell(row, col);
    }
  }
}
```

This function loops through every cell and draws it.

The function name tells us what the code does:

```js
drawGrid();
```

That is easier to understand than reading all the loop code every time.

---

## Key Idea

A function is a reusable block of instructions.

Basic structure:

```js
function functionName(input) {
  // instructions
  return output;
}
```

Example:

```js
function double(number) {
  return number * 2;
}
```

Use the function:

```js
let result = double(6);
```

Now:

```js
result = 12;
```
